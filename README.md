# Handoff

One task list for a company's people and agents.

Each company gets its own workspace on a subdomain (`acme.<your-domain>`) or its own domain. People use the web app; the company's agents (Claude, ChatGPT, Codex, Cursor, internal bots) read and write the same list through one remote MCP endpoint, each as a named member with its own permissions.

Status: early development.
